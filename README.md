# Python 学习代码（basic-code）

> Python 零基础跟着 B 站「黑马程序员」课程逐章敲的练习仓库，外加洛谷 / 力扣题解。

## 简介

系统学 Python 的**主仓库**：课程章节练习 + 算法题库两条线。
目标不是「看懂视频」，而是**合上视频自己复写一遍** —— 所以每题都带注释，写崩了也留着。

## 技术栈

| 层 | 用了什么 | 版本 / 说明 |
|---|---|---|
| 语言 | Python | 3.13（本机）；判机环境见各题注释 |
| IDE | PyCharm | 解释器在 `.venv/`（不进 git） |
| 第三方库 | 课程用到的库 | 按章节各自安装，暂未统一 `requirements.txt` |
| 判题平台 | 洛谷 / 力扣 | 题解按题单 + 难度分层存放 |
| 版本控制 | Git | 78 条提交 |

## 特性

- 按**课程章节**分目录，一个知识点一个文件
- 洛谷题库按「题单 → 难度」二级分层，找题很快
- 题解**一律带中文注释**（含踩坑记录）
- 娱乐目录放写着玩的小东西，不影响学习主线

## 快速开始

### 环境要求

- Python 3.13（低版本个别语法会报错）
- 任意编辑器 / IDE（推荐 PyCharm）

### 安装

```bash
git clone <你的仓库地址>
cd basic-code
python -m venv .venv
```

### 运行

```bash
python 第一章-认识Python/xxx.py
```

或在 PyCharm 里直接右键 → Run。

## 使用示例

```python
# 洛谷 P5728 旗鼓相当的对手（节选）
n = int(input())
for _ in range(n):
    a, b, c = map(int, input().split())
```

## 开发

- **一处一文件**，文件名带题目号，方便回头找；
- 提交信息统一 `feat(洛谷题库): …` 之类的风格，看历史能一眼知道加了什么。
